# RAG Security — Interactive Walkthrough

A self-contained, browser-based walkthrough of the RAG Security SVG diagram.

## Run locally

Open `index.html` in a modern browser. The page includes the SVG and all presentation logic; no build step or external dependencies are required.

## Controls

- Previous / Next scene buttons
- Auto-play
- Keyboard navigation with the arrow keys and Space

## Deploy

This is a static site. It can be deployed directly to Vercel, GitHub Pages, or any static hosting provider. The root `index.html` is the site entry point.
